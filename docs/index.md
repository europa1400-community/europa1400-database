# Europa 1400 Database

Which versions of **Europa 1400: The Guild** (*Die Gilde*) exist, and which community patches and fixes fit them.

Players do not need to install anything from here: the
[Europa 1400 Manager](https://europa1400-community.github.io/europa1400-manager/) reads this database and installs the
right patches for the game.

- [Tables](tables/index.md): editions, versions, executables and patches
- [Articles](articles/index.md): background and guides
- [Source on GitHub](https://github.com/europa1400-community/europa1400-database): add a version or a patch
